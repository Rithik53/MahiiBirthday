# assets/

Drop your files here.

## 🎵 The song

1. Download the song as an audio file (`.mp3` works best across browsers).
2. Put it in this folder.
3. Open `js/config.js` and set the path, e.g.:

   ```js
   songPath: "assets/our-song.mp3",
   ```

The song loops quietly in the background. There's a ♪ button (top-left) to
mute/unmute. Note: mobile browsers block autoplay until the first tap, so music
kicks in the moment she taps **Open the sky** on the first screen — that's
expected. Something soft/dreamy suits the night-sky mood.

> Only use a song you have the right to use. This is a personal gift — keep it
> to personal use.

## 🌌 Images (optional)

You don't need any images — the stars, moon, shooting stars, and lanterns are
all drawn in code. If you want to add extra sky/birthday-themed graphics, use
royalty-free assets (Unsplash, Pexels) or your own.

**Don't use her personal photos.** Keep filenames simple (no spaces), e.g.
`stars.png`, then reference them in your own custom scenes if you extend it.
